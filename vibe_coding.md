# Vibe Coding Workflow

## Project
Habit Tracker Application

## Feature Added
Habit Streak Tracking

## Objective
Track consecutive days a user completes a habit and display the current streak.

---

## Prompt 1

Create a Flask-based Habit Tracker application.

Requirements:
- Add new habits
- Delete habits
- Mark habits as completed
- Display all habits
- Use a simple and clean UI

---

## Prompt 2

Add a Habit Streak Tracking feature.

Requirements:
- Track consecutive days a habit is completed
- Show current streak beside each habit
- Reset streak when a day is missed
- Keep the implementation simple and maintainable

---

## Prompt 3

Create a separate streak.py module for streak calculation logic.

Requirements:
- Calculate consecutive completion days
- Return current streak count
- Handle edge cases such as missing dates

---

## Prompt 4

Generate automated tests for the streak feature.

Requirements:
- Verify streak increases for consecutive days
- Verify streak resets after a missed day
- Test edge cases

Expected file:
tests/test_streak.py

---

## Prompt 5

Improve the user interface.

Requirements:
- Display streak count beside each habit
- Show streak badge
- Keep the layout clean and responsive

---

## Development Approach

The feature was developed iteratively through direct AI prompting without creating a formal specification beforehand.

Workflow:

Prompt → Generate Code → Test → Refine Prompt → Update Code
